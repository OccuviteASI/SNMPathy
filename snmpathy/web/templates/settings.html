{{ icon('grafana') }} Grafana

SNMPathy is a data source for the Grafana JSON plugin (simpod-json-datasource). With Docker, docker compose --profile grafana up -d provisions everything automatically. For an existing Grafana:

  1. Install the plugin: grafana-cli plugins install simpod-json-datasource (or set GF_INSTALL_PLUGINS=simpod-json-datasource).
  2. Add a data source of type JSON with the URL {{ settings.public_url or base_url }}/grafana and UID snmpathy{% if settings.api_token %}, plus a custom HTTP header X-API-Key set to your API token{% endif %}.
  3. Import the dashboards below (Dashboards → New → Import → Upload JSON).
{% for b in grafana_boards %}{{ icon('download') }} {{ b.title }}{% endfor %}

Query types: metric, check, syslog, count, and tables devices, checks, interfaces, alerts, syslog_events, events, top. Template variables: devices, tags, checks, keys, interfaces <device>, hosts.
